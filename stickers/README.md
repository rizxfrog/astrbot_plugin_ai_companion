# 表情包放这里

把表情包图片按**情绪分类**放进子文件夹，文件夹名就是分类名：

```
stickers/
├── 开心/     😄.jpg   🎉.png
├── 无语/     ....gif
├── 生气/     😠.png
├── 撒娇/     🥺.webp
└── 通用/     hi.png
```

- 支持格式：`.jpg` `.jpeg` `.png` `.gif` `.webp` `.bmp`
- 直接放在 `stickers/` 根目录下的图片会自动归入 **通用** 分类
- **通用** 是兜底池：AI 想要表情但分类写错、或想随机来一张时，都从这里取
- 新增或删除图片后，重载插件即可生效（无需重启 AstrBot）

## 推荐放置位置

优先放在插件的**数据目录**（不会被插件更新覆盖）：

```
data/plugin_data/astrbot_plugin_ai_companion/stickers/
```

插件目录下的 `stickers/` 也可以放（本目录），两者都会扫描。

## AI 怎么用

插件会把可用分类告诉模型，模型在回复里写：

```
好耶！[sticker:开心]
```

插件在消息发出前把标记换成一张真实的 `开心` 分类图片。
标记不会泄露给用户，也不会留在聊天记录里。

也可以配置 `sticker_auto_probability`，让 AI 在没主动发表情时按概率自己补一张。
